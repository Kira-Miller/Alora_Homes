# Alora Homes — Портал недвижимости по всей Беларуси

Статический многостраничный веб-сайт агентства недвижимости **Alora Homes** (г. Минск и все 6 областей Республики Беларусь, включая малые города). Проект работает **полностью на стороне клиента без бэкенда** и готов к публикации напрямую на **GitHub Pages**.

---

## Основные возможности

- **Каталог из 24 объектов по всей Беларуси:** Минск, Ратомка, Раубичи, Новая Боровая, Слуцк, Волковыск, Смиловичи, Брест, Пинск, Барановичи, Гродно, Лида, Витебск, Полоцк, Новополоцк, Гомель, Жлобин, Могилёв, Бобруйск.
- **Хранение каталога в XML (`data/properties.xml`):** динамическая загрузка и разбор через `DOMParser` с автоматическим резервным источником (`src/js/properties-data.js`).
- **Умный поиск и геолокация:** подбор ближайшего города через Geolocation API с автоматическим резервным определением по IP, быстрый выбор городов, сброс поля и живой подсчёт совпадений.
- **Интерактивная карта Беларуси (SVG):** зум до `8x`, панорамирование, жесты двумя пальцами на смартфонах, быстрое приближение к Минску и области, боковая карточка выбранного объекта.
- **16 интерактивных планировок этажей (SVG):** переключение уровней и кликабельные комнаты с отображением площади, отделки и ориентации по сторонам света.
- **Онлайн-калькулятор оценки и услуги:** пошаговая оценка стоимости недвижимости и форма заявки с загрузкой превью фото и маской белорусского телефона `+375 (XX) XXX-XX-XX`.
- **Аналитика рынка (SVG-графики):** динамика цен за м² по регионам и годам с горизонтальной прокруткой на мобильных экранах и советами покупателям.
- **Личный кабинет и гостевой режим:** регистрация, избранное, таблица сравнения объектов, заявки на показ с выбором консультанта и мини-карточкой специалиста, публикация отзывов.
- **Интерфейс и печать:** переключение языка (**RU / EN**), темы (**Тёмная / Светлая**), валюты (**BYN / USD**), копирование ссылки и экспорт карточки объекта в **PDF / Печать**.

## Стек и архитектура (без бэкенда)

| Технология | Назначение |
| --- | --- |
| **HTML5** | Семантическая разметка (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`) и 7+ страниц |
| **XML** | База объектов недвижимости `data/properties.xml`, читаемая через `DOMParser` |
| **SCSS + CSS3** | Модульная архитектура стилей (`src/scss/*.scss`), компилируемая в `css/main.css` (Grid, Flexbox, CSS Variables, `@media`, `@media print`) |
| **SVG** | Векторный логотип, иконки, карта Беларуси, графики аналитики и поэтажные архитектурные планировки |
| **JavaScript (ES6+ Modules)** | Полное управление DOM, маршрутизация параметров URL, фильтрация, валидация и хранение состояния |
| **localStorage** | Локальное хранение профиля пользователя, избранного, сравнения, заявок и отзывов (`alora_homes_state_v2`) |

> **Почему нет серверной части:** сайт полностью статический. Регистрация, заявки и сохранённые объекты хранятся локально в браузере каждого пользователя в `localStorage`.

## Локальный запуск и проверка качества

### Локальный просмотр

Поскольку модули JS и загрузка `data/properties.xml` работают по HTTP/HTTPS (из-за политики CORS для `file://`), для локального просмотра используйте любой локальный веб-сервер:

```bash
npm install
npm run dev
```

Открыть в браузере: `http://localhost:3000`

### Сборка SCSS в CSS3

```bash
npm run build:css
```

### Валидация и линтинг

- **W3C Markup Validation Service:** HTML5-разметка всех страниц и XML-структура проверены на соответствие стандартам (`<!doctype html>`, уникальные `id`, семантические теги, `alt`-атрибуты).
- **GitHub Super-Linter:** в `.github/workflows/super-linter.yml` настроена автоматическая проверка HTML5 (`htmlhint`), XML (`xmllint`), JavaScript (`eslint`), Markdown (`markdownlint`), YAML, JSON и компиляции SCSS при каждом push в ветку `main`.

## Деплой на GitHub Pages

При отправке изменений в ветку `main` workflow `.github/workflows/deploy.yml` автоматически собирает статический артефакт (`*.html`, `css/`, `src/`, `data/`, `assets/`, `.nojekyll`) и публикует сайт на **GitHub Pages**.
